# Berlin 연속 장애물 진입 후보 비교

가중치를 고정하고 기존 24개와 사전 추첨 30개 배치에서 설정마다 첫 랩 계획을 비우고 180초씩 주행했다. 공통 정상 속도 범위는 2.7~4.5m/s, 첫 랩 상한은 2.2m/s, 센서 보호 한계는 150ms다. 장애물 실제 위치·크기와 차량의 실제 포즈는 시나리오 생성 및 채점에만 쓰인다.

50%와 100%는 로컬 경로를 첫 랩의 전체 경로 쪽으로 얼마나 이동시킬 수 있는지를 나타낸다. 차량 바로 앞은 혼합량을 점진적으로 올린다. 각 후보에는 로컬 경로 유지 선택이 있고, 센서로 검증한 조향·제동 보호가 마지막 명령을 검사한다. 기존 1번은 50%와 100%를 모두 비교한다. 직전 TLN 유지 후보는 직전 신경망 조향을 직접 채택했다면 경로 변경에 필요한 점수 개선량을 높인다. 예측 실패 후보는 기존 가이드의 안전 롤아웃이 다음 진입점에 도달하지 못할 때 대안을 평가한다. 가까운 쌍 후보는 관측 점유 구간 사이 자유거리가 현재 속도로 0.70초 동안 이동할 거리 이내일 때만 두 후보를 평가한다. 단계적 후보는 다음 진입점의 위치 오차 0.20m 이하, 방향 오차 0.20rad 이하, 예측 여유 0.10m 이상을 함께 충족하면 더 큰 경로 변경을 생략한다.

## 오프라인 결과

통과 기준은 180초 무정지·무충돌이다. 후속 랩 채택률은 각 설정에서 완주한 2랩 이후의 모든 Avoid 제어 주기를 합산했다. 보호 정지 전 완주한 랩도 포함한다. 구간 비교는 트랙 진행방향으로 간격 0.5~5m인 연속 장애물에서 첫 중심 1m 전부터 다음 중심 0.5m 후까지다. 동일한 배치·장애물 쌍·랩 번호를 모든 설정에서 완주한 경우만 비교했다. 구간 시간은 진행거리 경계에서 보간해 배치별로 평균 후 같은 비중으로 합산했다. 구간 채택률은 경계에서 나눈 Avoid 체류시간을 합산했다. 최소 여유는 차체와 장애물 분리축 여유이며, 경계에 일부 걸친 제어 구간에서도 물리 스텝 최솟값을 포함했다.

## 선발 결과

180초 완주·무충돌, 전체 최소 여유와 공통 구간 최소 여유 유지, 전체 후속 랩 채택률 85%를 먼저 적용하고, 만족한 후보 중 공통 배치의 평균 후속 랩이 빠른 `coupled`를 ROS 대조에 사용했다. 선발 후보의 후속 랩 평균은 16.825초, 기존 1번은 16.814초다. 기존 24개와 사전 추첨 30개의 선발 후보 채택률은 각각 85.42%, 86.04%다. 개별 배치 기준으로는 20개가 85% 미만이었다. 전체 최솟값이 유지됐어도 기존 1번에 비해 각 배치의 최소 여유가 1cm 이상 줄어든 배치는 5개였다. 속도와 개별 주행 기준을 함께 고려해 기존 기본 설정을 유지했다.

`pace-3-023` 6랩의 동일 상태에서 50% 후보는 통로를 잃고 정지했다. 100% 후보와 선발 후보는 같은 진입을 약 1.657초에 통과하며 15.36cm 여유를 확보했다. 이 한 구간의 TLN 직접 채택률은 약 51.7%였다. 전체 평균 채택률과 개별 통과의 채택률은 다르게 해석해야 한다.

## 재현

기존 공통 속도·전체 경로 실험의 프로필에서 `EL_CLUSTER_ENTRY=true`, `EL_SMOOTH_ISOLATED_EXIT=false`를 사용한다. `EL_ENTRY_CANDIDATES`와 오프라인 사양의 `entry_candidates`에 같은 이름을 쓴다. 선택지를 생략하면 기존 1번이며, 로컬 단독 실험은 `cluster_entry=false`다.
- `both` — 기존 1번
- `half` — 50% 후보
- `full` — 100% 후보
- `continuity` — 직전 TLN 조향 유지 우선
- `rescue` — 로컬 예측 실패 때만 전환
- `coupled` — 가까운 두 점유 구간에만 적용
- `graduated` — 진입 자세를 충족하면 탐색 종료

진입 비교의 [배치 사양과 결과](v1.5/)를 저장소에 포함했다. Docker에서 같은 체크포인트를 다시 생성해 분기하는 명령은 [v1.5 실행 방법](../../README.md#v15--다른-pc에서-berlin-주행하기)에 있다. 각 배치는 과거 개발에 사용됐고 ROS 대조는 설정·배치당 1회다.
