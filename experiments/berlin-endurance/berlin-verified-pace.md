# Berlin 정방향 4.5 m/s v1.5 랩타임 실험

Race 조향이 풀리고 첫 랩에서 만든 계획이 가속을 허용할 때, 라우터가 시야·곡률·모델 출력 범위에서 후보 속도를 계산한다. 명령 적용 지연을 포함한 250ms 주행과 뒤이은 정지가 가능할 때 가속한다. Race에서는 6cm의 추가 여유로 다음 제동 궤적을 확인한다. Avoid TLN 조향 검증에 실패하면 기존 대안 중 예측 충돌이 가장 늦은 조향을 우선하고 동률일 때 기존 경로 비용으로 정한다.

실험 옵션은 `race_verified_pace`이며 기본값은 꺼짐이다. 기존 v1.5 실행에 `EL_RACE_VERIFIED_PACE=true`를 추가하면 ROS 시뮬레이터에서 재현할 수 있다. Race 상한은 4.5m/s, Avoid 범위는 2.7~3.0m/s, 센서 보호는 150ms다. 평가에는 같은 Race·Avoid 가중치를 썼고 각 실행은 첫 랩에서 계획을 새로 만들었다. 제어에는 LiDAR 기반 위치 추정과 정적 지도를 썼다. 물리 충돌과 랩은 평가기가 별도로 판정했다.

## 개발 배치

| 같은 24개 배치 | 기존 TLN 우선 | 새 기능 |
|---|---:|---:|
| 180초 무정지·무충돌 | 24/24 | 24/24 |
| 배치별 최고 랩 평균 | 16.850초 | 16.542초 |
| Avoid TLN 직접 채택 | 88.14% | 88.30% |
| 180초당 평균 Avoid 시간 | 78.76초 | 79.57초 |
| 전체 최소 장애물 여유 | 12.37cm | 7.95cm |
| 총 완주 랩 | 233 | 236 |

기능을 끈 같은 바이너리에서 기존 랩 기록이 재현됐다. 24개 모두 빨라졌다. 스카우트 랩을 제외한 같은 위치의 208랩에서 장애물 3m 밖에서는 랩당 0.281초, 통과 직후 3m에서는 0.021초를 줄였다. 최종 오프라인 172,776회 제어에서 25ms 초과는 기능을 끄면 1회, 켜면 3회였다. 후보 최대는 35.90ms였고, 해당 주기의 메모리 단계는 경과 29.27ms, 스레드 CPU 1.01ms였다.

ROS는 장애물 1·3·5개 대표 배치에서 각 3개 노이즈 시드로 실행 순서를 교차했다. 기존 설정은 8/9, 새 기능은 9/9가 통과했다. 양쪽이 모두 완주한 8쌍 모두 빨라졌고 평균 단축은 0.367초였다. 기존 설정은 장애물 5개 한 회에서 경과 46.39ms로 제어 마감을 넘겨 보호 정지했다. 로그 시각 정밀도 차이로 판정이 거절된 별도의 기존 1회는 마이크로초 정밀도를 맞춘 후 동일 원기록에서 180초 전체를 재채점했다.

300배치 중 286개가 180초를 무정지·무충돌로 완주했다. 첫 랩 완주는 296/300이고 물리 충돌은 0건이었다. 0랩인 배치 4개를 제외한 배치별 최고 랩 평균은 16.695초다. 180초 또는 10랩 중 먼저 도달하는 대회 방식에서도 286/300이 무정지로 통과했고 184개는 10랩에 도달했다. 직접 채택률은 전 배치 합산 87.62%였다.

기능을 켰을 때 실패한 14개만 같은 배치·노이즈로 끄고 재생하자 6개는 완주했고 8개는 양쪽 모두 실패했다. 첫 랩 실패 4개는 양쪽 모두 발생했다. 사전 추첨한 30개의 오프라인 비교에서 기존은 28/30, 새 기능은 28/30을 완주했고, 양쪽이 완주한 27쌍의 평균 최고 랩 차이는 -0.238초였다.

사전 추첨 30개를 ROS에서 각각 180초 주행한 결과는 29/30이었다. 물리 충돌을 기록한 배치는 0개였다. 실패별 원인은 아래와 같다.

- `pace-3-023` · 1랩 · `no_corridor`

새 기능은 실험 옵션으로 유지한다. 미지 배치에서 기존이 완주한 6개가 새로 정지했기 때문에 4.75m/s 이상 시험은 보류했다. 다음 비교 대상은 해당 6개에서 통로가 처음 달라진 진입 상태와 네 가지 첫 랩 실패다.
