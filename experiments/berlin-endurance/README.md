# Berlin 180초 연속 주행

Berlin 정방향에서 첫 제어부터 180초를 측정한다. 랩 수 상한은 없다. 각 배치는 장애물과 노이즈 시드를 고정하고 첫 랩 계획을 비운 상태에서 출발한다. 180초 동안 무접촉·무정지, 보호 거부 0, 결승선 통과 1회 이상이면 통과다. 출발 0.5m 이후 물리 속도가 0.05m/s 아래로 내려가면 정지로 기록한다. 실패한 배치에서도 최초 실패 이전의 연속 완주 수를 남긴다. 대회에서 적용하는 최대 10랩 제한은 이 실험에 적용하지 않았다.

세 상한 모두 기존 300개에서 물리 접촉은 0회였다. 3.5m/s의 180초 통과는 292회, 3.65m/s는 292회, 3.75m/s는 290회다. 세 설정이 함께 통과한 289개의 평균 베스트랩은 16.560초 → 16.471초 → 16.414초였다. 기존 통과 배치를 잃는 후보가 있어서 기본 실행 설정은 유지하고 직선 가속을 선택할 수 있게 했다.

## 속도 제어

기존 탐색기와 원본 Avoid 가중치를 사용했다. 첫 랩에서는 동일하게 탐색하고, 이후 Race에서만 추가 가속을 허용한다. 현재 조향과 신경망의 요청 조향, 전방 경로 곡률, 첫 랩에서 기록한 감속 계획을 검사한다. 정면 ±0.12rad 시야에서 제동거리와 지연 여유를 확보한 경우에만 3.5m/s 위의 상한을 사용한다. 기존 제동 예측과 최종 발행 명령 검사는 그대로 수행한다. 기준 조건은 Race 상한 3.5m/s, 계획된 Avoid 범위 2.7–3.0m/s, 센서 보호 150ms, 제어 시간 보호 25ms다. 주행에는 LiDAR와 Berlin 정적 지도를 사용하며 시뮬레이터의 충돌·위치 정보는 독립 판정에서만 사용한다.

## 실험 설계

- 예비 배치 15개에 같은 센서 노이즈와 장애물을 사용해 3.5, 3.65, 3.75m/s를 비교했다. 모두 15/15 통과, 평균 베스트랩은 16.629초, 16.523초, 16.485초였다. 3.75m/s를 본평가 후보로 고정했다.
- 직전 실험에서 추첨한 300개를 장애물 1·3·5개 각 100개씩 재사용했다. 이번에 별도로 고정한 미사용 30개는 각 10개씩이다. 예비 15개와 미사용 30개는 [layouts.json](layouts.json), 검증 입력과 모델 해시는 [protocol.json](protocol.json)에 있다.
- 오프라인에서는 Gym 물리 시간 180초를, ROS에서는 첫 제어 샘플에서 시작하는 단조 시각 180초를 채점했다. ROS는 종료 여유를 두고 녹화한 뒤 180초 창 안의 물리 샘플과 결승선 통과만 채점한다. 실패 후에는 그전까지의 연속 랩 수를 기록한다. 점유·제동 보호에 의해 멈춘 주행도 실패다.
- 평균 베스트랩은 전후 모두 180초를 통과한 동일 배치에서 구한 배치별 최단 랩의 산술평균이다. 연속 완주 합계에는 중도 실패 배치에서 실패 전에 달린 랩도 포함한다.

| 그중 장애물 1개 | 99 → 99 | 0 → 0 | 1053 → 1071 | 99 | 15.456 → 15.241 |
| 그중 장애물 3개 | 99 → 99 | 0 → 0 | 955 → 959 | 98 | 16.737 → 16.609 |
| 그중 장애물 5개 | 94 → 92 | 0 → 0 | 849 → 849 | 92 | 17.558 → 17.469 |

300개에서 기존 통과 후 후보 실패로 바뀐 배치 3건 (new-3-082, new-5-055, new-5-067), 기존 실패 후 후보 통과 1건 (new-3-091). 첫 랩 완주는 296 → 296회였다.

미사용 30개에서 기존 통과 후 후보 실패로 바뀐 배치 0건 (없음), 기존 실패 후 후보 통과 0건 (없음). 첫 랩 완주는 30 → 30회였다.

## ROS 결과 · 3.5m/s와 3.75m/s

장애물 수별로 고정한 한 배치를 동일한 가중치와 센서 노이즈 시드로 각각 한 번씩 주행했다. 주행 순서를 교차하고 다른 오프라인 작업과 물리 CPU 코어를 분리했다.

| 장애물 수 | 연속 랩 기준 → 후보 | 베스트랩 기준 → 후보 (초) | 후보의 충돌 / 정지 샘플 | 후보 제어 p99 / 최대 (ms) | 복귀 후 3.4m/s 도달 중앙값 기준 → 후보 (초) |
|---|---:|---:|---:|---:|---:|
| 1 | 10 → 10 | 15.844 → 15.718 | 0 / 0 | 11.68 / 12.41 | 0.40 → 0.38 |
| 3 | 10 → 11 | 15.747 → 15.604 | 0 / 0 | 11.15 / 13.14 | 0.78 → 0.71 |
| 5 | 8 → 8 | 18.438 → 18.398 | 0 / 0 | 11.57 / 12.04 | 0.32 → 0.23 |

복귀 시간은 첫 랩 이후 Avoid에서 Race로 전환한 뒤 다음 회피에 들어가기 전에 실제 속도가 3.4m/s에 도달한 사례에서 집계했다. 두 설정 모두 세 주행에서 정지와 접촉, 유효 제어 25ms 초과가 0회였다.

3랩만 통과하면 성공으로 판정할 경우 기존 300개에서 3.5m/s는 293회, 3.75m/s는 295회 성공이다. 180초 기준에서는 각각 292회와 290회였다. new-5-067은 3.75m/s에서 8랩 뒤 약 167초에 제동 궤적 보호로 멈췄다. 3.75m/s 명령이 실제로 기준 상한을 넘었던 ROS 시간(명령 >3.51m/s)은 180초 중 장애물 1·3·5개에서 각각 24.5초, 24.4초, 3.8초였다.

## 3.65m/s 추가 검증

3.75m/s가 기존 통과 배치에서 보호 정지를 일으켜 예비 단계에서 함께 시험했던 3.65m/s도 같은 300개와 미사용 30개에서 처음부터 다시 주행했다.

| 배치 | 3.5 → 3.65m/s 통과 | 연속 완주 합계 | 공통 통과의 평균 베스트랩 (초) |
|---|---:|---:|---:|
| 기존 300 | 292 → 292 | 2857 → 2871 | 16.568 → 16.479 |
| 미사용 30 | 30 → 29 | 290 → 289 | 16.658 → 16.562 |

3.65m/s에서 기존 완주 → 실패 1건 (new-3-082), 실패 → 완주 1건 (new-3-091). 세 속도로 모두 통과한 배치만 따로 비교한 수치는 [공통 배치 비교](common.json)에 있다. [3.65m/s 개별 결과](cap-3.65/paired.csv) · [3.65m/s 집계](cap-3.65/results.json)

## 첫 랩 실패 재생

이전 통로 탐색 후보에서 첫 랩 제동 보호가 걸렸던 네 배치의 진행거리 16m에서 시뮬레이터·스캔·추정 자세·제어기 상태를 저장했다. 같은 상태를 복원해 현재 기본 탐색기와 이전 후보를 분기했다. 기본 탐색기는 네 건 모두 첫 랩을 마쳤고 이전 후보는 네 건 모두 같은 제동 거부를 재현했다. 최초 명령 차이는 진행거리 19.16–19.72m에서 나타났다. new-5-041은 같은 자세에서 기본 조향 −0.30rad와 이전 후보 +0.40rad로 갈라졌다. 그래서 이번 속도 실험은 기본 탐색기를 사용하고 첫 랩 가속을 제한했다. ## 재현

프로젝트가 `/workspace`에 마운트된 기존 ROS Humble 개발 컨테이너에서 실행한다. 실행마다 새 출력 디렉터리를 사용한다. 기준과 후보의 짝 비교는 CPU 8–15번에서 두 개의 독립 ROS 도메인을 사용한다. 추가 상한만 시험할 때는 CPU 0–3번을 더 사용해 세 배치를 독립적으로 재생한다.

```bash
cd /workspace
source /opt/ros/humble/setup.bash
source /home/misys/forza_ws/race_stack/install/setup.bash
export PYTHONPATH="/home/misys/forza_ws/race_stack/base_system/f110_simulator/f1tenth_gym/gym:${PYTHONPATH:-}"
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 EVAL_CORES=0,2,4,6
export EL_SPEED_OUTPUT=/workspace/runs/berlin-endurance-replay
cmake --build /build --target el_eval_avoid el_controller
for suite in pilot matched holdout; do
  python3 experiments/berlin-endurance/offline.py "$suite" 3.5
  python3 experiments/berlin-endurance/offline.py "$suite" 3.65
  python3 experiments/berlin-endurance/offline.py "$suite" 3.75
done
python3 experiments/berlin-endurance/ros.py 3.75
python3 experiments/berlin-endurance/ros.py 3.65 --candidate-only
python3 experiments/berlin-endurance/summary.py "$EL_SPEED_OUTPUT" 3.75 --output "$EL_SPEED_OUTPUT"
mkdir -p "$EL_SPEED_OUTPUT/cap-3.65"
python3 experiments/berlin-endurance/summary.py "$EL_SPEED_OUTPUT" 3.65 --output "$EL_SPEED_OUTPUT/cap-3.65"
```
