# Berlin 정방향 기존 완주 4개 회귀 분석

84개 통과 빌드에서 완주했고 87개 통과 빌드에서 새로 실패한 네 배치를 두 빌드로 다시 주행했다. 양쪽 모두 보관된 원래 랩 기록·최초 거부 기록이 재현됐다. 두 기록을 누적 진행 거리로 정렬하고, 최초 거부의 센서 점유 격자에서 탐색 단계별 자유 후보와 도달 후보의 수를 대조했다.

|---|---|---:|---:|---:|---|
| 4135410 | 1랩 23.65 m | 3 | 66 | 2 → 0 | 두 번째 장애물 진입 시 기존 완주차는 기준선 왼쪽 0.65 m였다. 실패차는 거의 기준선 위에서 통로를 바꾸려 했다. |

기존 탐색은 기준선 방향으로 약 20 cm 전진하는 동안 옆 열로 최대 10 cm만 이동할 수 있었다. 2.5 cm 간격으로 열을 세분화해도 이 제한은 같았다. 점유 격자를 고정하고 횡방향 연결을 확장하면 네 상태 모두 통로가 나왔다. 장애물 판정을 완화할 필요는 없었다.

최종 C++ 탐색기는 일반 탐색이 모두 실패하면 5 cm 간격의 격자에서 한 단계에 최대 30 cm까지 옆으로 이어지는 후보를 검사한다. 이는 계획 후보의 범위다. 실제 명령에는 기존 차량 점유 영역, 지연을 포함한 조향·제동 예측, Gym 전방 TTC 검사를 적용한다. 새 탐색이 최초로 작동한 차량 자세와 제어 주기는 네 시드 모두 기존 최초 실패와 일치했다. 첫 복구 경로에서 한 단계의 최대 횡이동은 각각 30, 20, 25, 20 cm였다.

ROS 중간 검증에서는 9157059의 첫 랩 누적 36.69 m에서 회피 측면이 바뀌었고, 직전 7개 제어 주기에서 음의 조향 한계 근처를 사용했다. 해당 프레임의 제동 궤적이 점유 영역과 겹쳐 `braking_footprint`로 정지했다. 최종 라우터는 회피 명령이 거부될 때 현재 조향, 직진, 양쪽 조향과 감속 후보를 동일한 정지거리·차체·Gym 충돌 검사로 평가한다. 모두 거부되면 기존과 같이 정지한다. 2·3랩의 대체 명령에도 설정된 회피 하한을 적용한다. 이 변경만 적용한 두 번째 ROS 검증도 7/8이었다. 9157059가 같은 지점에서 다시 정지했다. 성공 기록에서 차량은 장애물 오른쪽으로 계속 선회했지만, 실패 기록에서는 36.50 m에서 반대 방향 조향을 명령했다.

최종 변경은 첫 랩에서 장애물을 회피하던 차가 큰 조향각을 풀 때 작동한다. 지연을 포함한 차량 모델로 0.25초간 선회하고 제동을 마칠 때까지의 차체 여유를 계산한다. 새 조향의 여유가 작고 직전 조향의 여유가 더 크면 그 제어 주기에는 직전 조향을 유지한다. 다음 센서 관측에서 다시 판단한다.

## 오프라인

같은 100개 배치, 같은 시작 웨이포인트·장애물 좌표·내부 난수 시드로 빈 계획에서 3랩을 주행했다. 원본 Avoid와 WSP Race, 계획 주행 회피 목표 속도 하한 2.7 m/s, 센서 보호 150 ms를 유지했다. 통과 조건은 3랩 완주, 출발 이후 주행 중 정지·안전 거부·충돌 없음, 2·3랩 계획 감속 작동이다.

최종 통과는 95/100이다. 기존 87개 모두 통과했고 이 중 85개는 랩타임과 이벤트를 포함한 평가 결과 전체가 같았다. 기록이 달라진 6172719의 3랩 합계는 64.85초에서 61.84초로, 5355619는 61.71초에서 61.72초로 바뀌었다. 4135410, 5557822, 6695374, 7625705, 7784311, 9157059, 9285660, 9865006이 새로 통과했다. 1846076, 2238863, 8181110, 9699447, 9701112는 여전히 no_corridor로 정지했다. 충돌은 0건이었다. 앞서 통로 선택 자체를 바꾼 비교 후보는 네 회귀를 모두 해소했으나 전체 81/100, 기존 완주 배치의 새 실패 12건이어서 채택하지 않았다.

## 재현

기존 el-native-dev 컨테이너의 /workspace에서 새 결과 이름으로 실행한다. ros.py는 이전 검증과 같이 16논리 CPU 호스트에서 두 CPU 그룹과 별도 ROS 도메인을 사용한다. 테스트에 추가한 네 점유 격자와 자세는 각 배치가 처음 실패한 프레임이다.

```bash
source /opt/ros/humble/setup.bash
source /home/misys/forza_ws/race_stack/install/setup.bash
export PYTHONPATH="/home/misys/forza_ws/race_stack/base_system/f110_simulator/f1tenth_gym/gym:${PYTHONPATH:-}"
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
cmake --build /build -j2
ctest --test-dir /build --output-on-failure
cd /workspace/runs/berlin-corridor-regressions
python3 evaluate.py repeat-100 /build/el_eval_avoid all
python3 ros.py repeat-ros
python3 audit.py repeat-100 repeat-ros
```
