# Berlin 정방향 무작위 장애물 100개 배치

오프라인에서 84/100개 배치가 정지·충돌 없이 3랩을 완주했다. 오프라인 실패 16개 중 ROS에서도 실패한 배치는 13개였다. 오프라인 통과 배치 중 장애물 여유가 가장 작았던 9006203은 별도로 두 번 ROS에서 확인했다.

## 조건과 판정

- 이전 캠페인과 동일한 C++ 탐색기, WSP Race, 원본 Avoid를 사용했다. 제어기와 모델의 SHA-256은 [hashes.json](hashes.json)에 있다.
- 기존 Berlin 무작위 배치기로 장애물 3개를 놓았다. 시드 추출용 난수 시드는 20261123이며, 100개 배치의 시드·웨이포인트·횡오프셋을 평가 전에 고정했다. 기존 배치 목록과 중복된 시드는 0개였다. 차량은 매번 웨이포인트 37에서 정방향으로 출발했다. 오프라인 시뮬레이터의 내부 시드는 이전 시험과 같은 12345로 고정했다.
- 배치마다 첫 랩부터 시작해 새 계획을 기록했다. 오프라인 평가기는 배치마다 라우터·지도 메모리·시뮬레이터를 새로 생성했고, ROS는 별도 프로세스의 첫 행에서 계획이 비어 있었는지 검사했다. 회피 목표 속도 범위는 계획 주행에서 2.7–3.0 m/s이며, 첫 탐색 랩에는 기존 감속 정책을 그대로 썼다.
- 오프라인 제어 주기 25 ms, 장애물 크기 0.30 × 0.30 m, 센서 보호 기준 150 ms. 3랩 완주, 주행 중 충돌·보호 정지 없음, 출발 0.5 m 이후 측정 속도 0.05 m/s 미만 없음으로 판정했다. 결승선 통과 후 정지 명령은 정상 종료다.
- 여유는 차체와 장애물 사각형의 분리축 투영 거리(SAT gap)다. 한 쌍의 사각형에 대해 네 축 중 가장 큰 값을 취하고, 세 장애물과 전체 주행에서 가장 작은 값을 기록했다. 오프라인에서는 물리 스텝마다, ROS에서는 수신한 지상진실 오도메트리마다 계산했다. 벽까지의 거리는 이 지표에 포함되지 않는다.

## 오프라인 결과

84개가 통과했다. 충돌은 0건이었으며, 보호 정지 16건 중 15건은 no_corridor, 1건은 braking_footprint였다. 14건이 첫 랩에서, 2건이 둘째 랩에서 발생했다.

통과 배치의 랩타임 중앙값은 28.09 / 18.04 / 18.00초였다. 통과 배치들의 최소 분리 여유 중앙값은 29.25 cm였다. 가장 작은 값은 random-9006203의 10.64 cm였다.
