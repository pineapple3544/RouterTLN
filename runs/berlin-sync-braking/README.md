# Berlin 정방향 시각 정합과 제동 예측

원본 Avoid, WSP Race, 첫 랩 탐색 주행, 계획 주행의 회피 목표 속도 하한 2.7 m/s, 센서 보호 150 ms를 유지했다. 수정 후 두 시드 모두 ROS 2 Humble 시뮬레이션에서 각 2회, 매회 새 계획으로 3랩을 완주했다. 같은 100개 오프라인 배치에서 84개였던 통과 수는 87개가 됐다. 전체 무정지 기준은 아직 달성하지 못했다.

## 수정

- ROS는 최근 스캔 중 오도메트리와 취득 시각을 맞출 수 있는 가장 새로운 스캔을 선택한다. Gym의 공통 타임스탬프는 정확히 일치해야 한다. 독립 시계를 쓰지 않고 공통 시각계에서 비동기로 발행하는 하드웨어 입력은 앞뒤에 각각 30 ms 이내의 측정값이 있는 경우에만 위치와 각도를 보간한다. 연속으로 입력을 맞출 수 없을 때도 150 ms 보호가 작동한다. 하드웨어 주행은 이번 검증 범위에 포함되지 않았다.
- 조향 후보의 궤적 계산은 이전 명령을 물리 스텝 1개 더 적용한 상태에서 시작한다. 이후 2스텝 조향 버퍼와 조향 속도 제한을 적용한다. 통로 선택에는 직전 계획과 현재 횡위치를 반영하고, TLN 조향에서 크게 벗어나는 후보의 비용을 높였다.
- 제동 가능 여부를 검사할 때도 이전 명령의 적용 지연을 고려한다. 차량 직사각형 검사와 함께 센서의 전방 오프셋 0.27 m, 휠베이스의 절반, 5 ms의 접근 거리에 해당하는 Gym 전방 TTC 영역을 점유 지도에서 검사한다. 제어기는 장애물 정답 좌표를 받지 않는다. 이 검사는 Gym 전방 빔 판정의 보수적 근사이며, 독립적인 실제 Gym 충돌 플래그를 평가에 사용했다.

## 실패 직전 기록 재생

기존 ROS 주행의 자세·명령 이력과 같은 Gym으로 스캔을 재구성했다. 5557202의 스캔 난수 위상은 초기 14개 제어 출력으로 식별했다. 이전 제어기로 검산한 결과, 보호 정지까지 667개 주기의 기억된 셀 수가 일치했고 666번에서 원래의 braking_footprint가 발생했다. 새 제어기는 과거 측정 궤적에 새 시각 정합과 라우터를 적용해 지도를 복원한 뒤, 지정된 위치부터 자유 주행했다. 물리 상태는 과거 차량이 이미 도달한 상태다.

| 시드 | 통과한 복원 지점 (누적 m) | 보호 정지가 남은 복원 지점 |
|---|---|---|
| 9006203 | 37.59, 39.79, 40.29 | 40.59 m에서 시작하면 40.75 m에서 braking_footprint |
| 5557202 | 28.09, 30.09, 32.09, 33.09, 33.59 | 34.39 m에서 시작하면 첫 제어 주기에서 braking_footprint |

재생 통과선은 세 번째 장애물을 지난 누적 43.5 m다. 보호 정지 분기는 최초 거부에서 종료했다. ROS의 3랩 시험과는 별도다.

## ROS 검증

두 시드 모두 장애물 3개의 실제 발행 좌표를 대조했다. 출발할 때 계획·전환·감속 기록은 모두 0이었다. 첫 랩을 마친 48.784 m에서 계획이 준비됐고 2·3랩에 감속 계획이 실행됐다.

| 시드 | 1회차 1·2·3랩 (초) | 2회차 1·2·3랩 (초) |
|---|---|---|
| 9006203 | 27.12 / 18.08 / 18.00 | 27.33 / 18.10 / 18.00 |
| 5557202 | 23.63 / 16.40 / 16.37 | 23.62 / 16.43 / 16.33 |

4회 12랩에서 주행 중 정지·충돌·센서 타임아웃은 각각 0건이었다. 처리에 사용한 모든 스캔·오도메트리 쌍의 타임스탬프 차이는 0 ms였다. 최대 스캔 나이 26.65 ms, 최대 제어 연산 시간 18.41 ms였다. 별도 센서 중단 시험에서 약 240 ms간 입력을 끊자 sensor_timeout이 걸렸고 마지막 속도는 0 m/s였다. CTest 8개를 모두 통과했다.

## 재실행

el-native-dev 컨테이너의 /workspace에서 빌드한다. ROS 및 오프라인 결과 디렉터리는 새 이름을 사용한다. 재생 스크립트는 해당 디렉터리의 진단 출력 파일을 작성한다.

```bash
source /opt/ros/humble/setup.bash
cmake --build /build -j2
ctest --test-dir /build --output-on-failure
cd /workspace/runs/berlin-sync-braking
bash replay_cases.sh
python3 campaign.py ros ros-repeat
python3 campaign.py offline offline-repeat
python3 audit.py repeat
```
